## Purpose

This roadmap outlines the evolution of the Top3 product experience.

Unlike the Technical Roadmap, this document focuses on the user experience rather than implementation details.

---

# Vision

Help people discover one another through shared taste.

Every roadmap item should strengthen one of these four pillars:

- Identity
- Discovery
- Connection
- Conversation

---

# Phase 1 — Identity ✅

Completed

- User Profiles
- Public Profiles
- Private Profiles
- Publishing
- Editing
- Profile Visibility
- Top3 Cards

---

# Phase 2 — Discovery 🚧

Current Focus

- Better recommendations
- Category browsing
- Trending
- Search improvements
- Discovery feed

---

# Phase 3 — Connection

Planned

- Notifications
- Rich comments
- Activity feed
- Better following experience

---

# Phase 4 — Intelligence

Future

- AI recommendations
- Weekly insights
- Taste evolution
- Similarity clusters

---

# Long-Term Vision

Top3 becomes the best place to discover people through shared taste.
