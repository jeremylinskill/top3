# Overview

The First Run Experience is the user's introduction to Top3.

Its purpose is not to teach the interface.

Its purpose is to help someone experience the core value of Top3 as quickly as possible.

The journey is complete when a user thinks:

> **"I found my kind of people."**

---

# Objective

Enable a brand-new user to:

- Create an account
- Build a profile
- Publish their first Top3
- Discover people with similar taste
- Follow another user
- Reach their personalized feed

...within five minutes.

---

# Product Goals

The onboarding should:

- Explain what Top3 is.
- Reduce friction.
- Encourage self-expression.
- Demonstrate Taste Match.
- Encourage the first follow.
- Lead naturally into the personalized feed.

---

# Non-Goals

This Epic does not include:

- Notifications
- Messaging
- AI recommendations
- Advanced profile customization
- Friend importing
- Contact syncing
- Premium features
